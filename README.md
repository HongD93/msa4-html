# msa4-html

HTML의 문서 구조와 기본 태그를 학습하는 예제 모음입니다. 텍스트·목록·표에서 이미지·링크·입력 폼까지, 주제별 파일을 브라우저로 열고 소스와 화면을 비교할 수 있습니다.

## 처음 시작하기

1. 저장소 전체를 내려받아 폴더 구조를 유지합니다.
2. [텍스트 예제](edu/01_text.html)를 웹 브라우저에서 엽니다.
3. 같은 파일을 코드 편집기로 열어 `h1`이나 `p`의 내용을 바꿉니다.
4. 파일을 저장하고 브라우저를 새로고침해 결과를 확인합니다.

웹 브라우저와 코드 편집기만 있으면 시작할 수 있습니다. 별도의 패키지 설치나 빌드 과정은 없습니다.

## 주제별 예제

| 예제 | 살펴볼 내용 |
| --- | --- |
| [01_text.html](edu/01_text.html) | 제목, 문단, 줄바꿈과 텍스트 강조 |
| [02_list.html](edu/02_list.html) | 목록 표현 |
| [03_table.html](edu/03_table.html) | 표 구성 |
| [04_image.html](edu/04_image.html) | 이미지 삽입과 경로 |
| [05_multimedia.html](edu/05_multimedia.html) | 오디오·비디오 삽입 |
| [06_a.html](edu/06_a.html) | 외부 링크와 같은 폴더의 문서 연결 |
| [07_form.html](edu/07_form.html) | `form`, `input`, `textarea`, `select`와 입력 속성 |

번호순으로 예제를 확인한 뒤 [tng/](tng/)의 복습 파일을 열어 연습할 수 있습니다. [edu/](edu/)와 [img/](img/)에는 예제에서 참조하는 이미지도 포함돼 있으므로 HTML 파일만 따로 옮기면 이미지나 문서 연결이 끊길 수 있습니다.

## 예제의 전제조건

- 멀티미디어 예제가 참조하는 `edu/vidio.mp4`는 저장소에 포함돼 있지 않습니다. 비디오 재생을 실습하려면 해당 경로에 개인 실습용 파일을 준비하거나 `src`를 수정하세요.
- 폼 예제는 입력 요소와 제출 방식을 관찰하는 용도입니다. 입력 데이터를 저장하거나 처리하는 서버 코드는 포함돼 있지 않습니다.
